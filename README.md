This is the project I have been working on for a long time now. It is an ESP32-based inventory manager and dashboard. Its primary purpose is to help me keep timers for studying, Pomodoro, and other activities. In addition, it tells me the location of almost 130 modules I own.

Looking into the details, I have an ESP32 as the main microcontroller, and I use most of its functionalities except Bluetooth. Next, we have the SSD1306 OLED module. I am looking to update it to a TFT display because the current OLED display is relatively small and difficult to see while sitting at my bench. The OLED display is followed by a small button, a toggle switch that I can use to turn it on and off, and an RTC module to track the time correctly because I will not be keeping the device turned on continuously, as I only have a 2,200 mAh battery in it.

Next, we have the most important part, of course: the keypad module. This is a 4-by-4 keypad module in which I have introduced a Nokia-style button keypad. Pressing a single button multiple times triggers a letter. For example, pressing button 5 twice gives the letter K.

this specific build has a lot of feature some of which are a timer and a time counter inventory surgery stopwatch Wi-Fi access to update the modules a clock using the RTC settings tab and inventory tracker where I can drag that in and modules I have returned
